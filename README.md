# 圆上的乘法

一个全屏、自动演化的 p5.js 数学作品。页面只保留图形，没有文字、控件或辅助网格。

## 运行

直接用浏览器打开 `index.html` 即可，不需要安装 npm 包。p5.js 1.11.11 保存在 `vendor` 中，页面无需联网。

也可以在此文件夹中启动静态服务器：

```sh
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。

每次加载都会生成一个随机种子，决定点数（240–600）、初始乘数（2–100）、配色和演化速度（每秒增加 0.12–0.22）。动画自动运行，刷新即可生成新的组合。画布跟随视口尺寸变化，圆的直径占视口较短边的 97%，保持正圆且完整可见。

## 原理

在圆周上等距放置 N 个点，编号为 0 到 N−1。对每个编号 i，连接起点 i 与终点 `(i × m) mod N`。终点可以不是整数，此时它位于对应的圆周角度，而不是把编号四舍五入。

点的位置为：

```
θ = 2π × i / N − π/2
x = cx + r × cos(θ)
y = cy + r × sin(θ)
```

乘数按经过的时间连续增加。N 是图形关于乘数的周期，因此乘数达到 N 时回到 0 不会产生跳变。返回后台标签页后从原来的图形继续，不快进。

## 文件

- `index.html`：全屏画布容器。
- `style.css`：视口布局。
- `sketch.js`：随机初始值、圆周乘法绘图与自动动画，使用 instance mode。
- `vendor/p5.min.js`：本地 p5.js 库。
- `vendor/p5.LICENSE.txt`：p5.js 的 LGPL-2.1 许可证。
